### 🧩 Featured Projects

**🔍 [Tracera — Deepfake Detection System](https://github.com/Mahmoud-Fathy5/Tracera)**
Forensic-grade image analysis platform powered by a custom architecture I built, GramNet v3, distinguishing real photos from GAN/Diffusion-generated images via Gram matrix correlation and eigenvalue profiling. Achieved **95.1% AUC / 88.6% accuracy** on held-out test data. Deployed as a Dockerized Flask API on Hugging Face Spaces, with a web dashboard and Chrome extension on top. Includes an undergraduate research paper on the underlying spatial-frequency pipeline.
`Python` `PyTorch` `Flask` `Docker` `XGBoost` `Hugging Face`

**🗣️ [Voxa — Offline Vocal-Intent Translator](https://github.com/Jasminex6/Project_Voxa)**
Fully offline Android app that translates the personalized vocalizations of non-speaking autistic children into Egyptian Arabic speech in real time. On-device pipeline using MFCC acoustic fingerprinting and DTW alignment, running inference in under 30ms with zero internet connection. Presented at CU AI Nexus Hackathon 2026.
`Kotlin` `Jetpack Compose` `TensorFlow Lite` `Signal Processing` `Room`

**🛒 [eCommerce API](https://github.com/Mahmoud-Fathy5/eCommerce-API)**
Backend REST API with dual-token JWT auth (httpOnly cookies, XSS/CSRF protection), atomic checkout via Prisma transactions, and role-based access control — built on clean MVC architecture.
`Node.js` `Express.js` `Prisma ORM` `PostgreSQL` `JWT`

**🍽️ [Restaurant Management System](https://github.com/Mahmoud-Fathy5/RestaurantManagement)**
Discrete-event simulation engine in C++17 modeling multi-stage restaurant logistics across 500+ customer lifecycle events, with custom data structures (Stack, Queue, Priority Queue) built from scratch — zero STL, strict pointer-based memory management.
`C++17` `Custom Data Structures` `Systems Design`

**📊 [Visual Flowchart IDE & C++ Code Generator](https://github.com/Mahmoud-Fathy5/phase_2_PT)**
Desktop visual IDE that lets users design flowcharts, validate their logic, simulate execution with a step-by-step debugger, and auto-generate compilable C++ source code — including reconstructing while-loops from cyclic flowchart branches.
`C++` `Win32 GUI` `Command/Mediator Patterns` `Code Generation`
